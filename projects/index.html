DnD Combat Assistant

Developed in F# | 10-10-2025

I really enjoy playing tabletop RPGs, although I find they all suffer from one issue: the god damn combat rules. There is nothing worse than being in the zone, and then someone else says, "uhmm, actually, you can't do that." Now, some people really enjoy reading the rulebook front to back, but I really don't. It just takes so much time for so little reward. There was only one logical solution to this problem: spend way more time than it would take to learn the rules, learning a new programming paradigm and making a program to do it for me.
